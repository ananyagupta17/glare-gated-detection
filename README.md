# Glare-Gated Object Detection

This project evaluates whether conditional glare restoration can recover object
detection accuracy in KITTI road scenes without paying the restoration cost on
every frame.

The pipeline compares three policies with the same YOLO detector and labels:

| Arm | Restoration policy |
|---|---|
| C1 | Never restore |
| C2 | Always restore |
| C3 | Restore only when the glare gate fires |

## Current status

| Component | Status |
|---|---|
| Deterministic four-type glare synthesis | Complete |
| KITTI YOLOv8n baseline | Complete |
| Binary glare gate | Complete on the synthetic held-out split |
| Flare7K++ Uformer adapter and demo | Complete |
| Full restored-dataset C2/C3 evaluation | Pending |
| Real daytime-glare validation | Pending |

The paired detector baseline fell from `0.6401` mAP@50 on clean images to
`0.2221` under synthetic glare. A verified restoration example improved PSNR
from `7.7907` to `14.4584` dB and SSIM from `0.439071` to `0.723428`. These
restoration values are from one representative pair, not a dataset average.

## Setup

Python 3.10 or newer is recommended.

```powershell
git clone https://github.com/ananyagupta17/glare-gated-detection.git
cd glare-gated-detection
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
```

The restoration adapter uses the Uformer architecture from the upstream
Flare7K repository. Clone it inside `external/`:

```powershell
git clone https://github.com/ykdai/Flare7K.git external/Flare7K
```

Alternatively, set `FLARE7K_REPO` to an existing Flare7K checkout.

The pretrained checkpoint is shared separately because it is 82.6 MB. Copy it
to `models/restoration/net_g_last.pth` and verify its checksum against
`models/restoration/README.md` before running the demo.

## Restoration demo

Run the included project example:

```powershell
.\run_restoration_demo.bat
```

Run a different image:

```powershell
.\run_restoration_demo.bat --input "C:\path\to\glared.png"
```

Run a paired image and calculate PSNR/SSIM:

```powershell
.\run_restoration_demo.bat `
  --input "C:\path\to\glared.png" `
  --clean "C:\path\to\clean.png"
```

Outputs are written to `results/restoration_demo/`, which is intentionally
ignored because it is regenerated by the command.

## Evaluation harness

`src/restore.py` exposes the interface consumed by `src/run_experiment.py`:

```python
restore(image: np.ndarray) -> np.ndarray
```

The input and output are same-sized `uint8` BGR images. After the KITTI images,
generated glare set, detector checkpoint and gate checkpoint are available, run:

```powershell
python src/run_experiment.py --restore auto --gate auto
```

## Important data rule

Use `data/glared_full/` and `data/glare_labels_full.csv` generated with seed 42.
Do not create a different glare set for team comparisons. The old 400-image
`data/glared/` set is retained only for provenance.

## Repository map

- `src/restore.py` — lazy CPU/CUDA Flare7K++ adapter used by the harness
- `src/demo_restoration.py` — single-image/folder demo and PSNR/SSIM reporting
- `src/run_experiment.py` — C1/C2/C3 evaluation harness
- `models/restoration/` — checkpoint placement and provenance
- `HANDOVER_RESTORATION.md` — teammate and agent handover context
- `THIRD_PARTY_LICENSES/` — upstream licence text for redistributed assets

## Limitations

- Flare7K++ is trained mainly for nighttime lens flare, while this project uses
  synthetic daytime sun glare.
- Saturated pixels may contain no recoverable scene detail.
- CPU Uformer inference is slow; use CUDA for the full dataset when possible.
- Improved PSNR/SSIM does not prove improved object detection. C2/C3 must be run
  before making that claim.
